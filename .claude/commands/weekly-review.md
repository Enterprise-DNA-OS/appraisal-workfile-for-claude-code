# /weekly-review

Run these three current reads:

```bash
node scripts/appraisal.mjs work-in-hand
node scripts/appraisal.mjs comp-check
node scripts/appraisal.mjs review-queue
```

Write the Monday review in the chat: due and overdue instructions by valuer, sales evidence needing attention, and complete workfiles waiting for review. Quote job codes and source gaps. Propose owners from the recorded work; never invent an inspection, sale verification, opinion or approval. Draft any client wording separately and never send.
