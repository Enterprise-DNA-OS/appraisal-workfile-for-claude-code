# Why this has no front end

The work is records, source evidence, comparisons and professional decisions. An operator can ask the agent to read and update those records directly. npm run view writes branded read-only HTML for the week, evidence gaps and sales comparisons. npm run docs writes draft workfiles and peer-review memoranda.

Valcre also supplies mobile capture, map views, linked Word and Excel templates, public data and licensed integrations. This base does not reproduce those services. It has no offline field app, drag-and-drop map, collaborative editor or public data feed. Store original documents separately and record their references.

Use this base when a trusted operator and the firm's own evidence can run the work. Enterprise DNA can build a field workflow, approved data connections or a custom screen when the practice needs them. A qualified valuer still chooses the approach and approves the final report.
